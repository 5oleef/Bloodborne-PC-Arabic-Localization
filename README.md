## ✨ المميزات الرئيسية

- **🇪🇬 تعريب بالمصري (العامية المصرية):**
  - **شاشات الموت:** `متّ خلاص يا صياد!` (بدلاً من لقد مت).
  - **شاشات الانتصار:** `دبحت الفريسة يا وحش!` و `قضيت على الكابوس خلاص!`.
  - **القوائم الرئيسية:** `المخزن`، `العتاد والتجهيزات`، `حالتك وصحتك`، `الضبط والإعدادات`، `النظام`.
  - **الأزرار والحوارات:** `تمام`، `إلغاء`، `أيوه`، `لأ`، `جرّب تاني`.
  - **الأدوات والأسلحة:** `إزازة دم (علاج سريع)`، `رصاص زئبقي`، `قزازة مولوتوف`، `ورقة نار`، `سيف المنشار القاطع`، `فأس الصياد`، `سيف لودفيج المقدس`.
  - **رسائل التنبيه:** `الباب مقفول ومش هيفتح من الناحية دي`، `معاكش أصداء دم كفاية`.
- **📜 تعريب فصحى كامل:** إمكانية الاختيار بين اللهجة المصرية أو الفصحى الرسمية بضغطة زر.
- **🔍 كشف تلقائي لمكان اللعبة:** يتعرف البرنامج على مكان اللعبة تلقائياً ويفحص صلاحية الملفات.
- **🛡️ تثبيت آمن بنظام المودات:** لا يتم تعديل أي ملف أصلي من اللعبة؛ يتم تثبيت التعريب كطبقة مود في مجلد `mods/Arabic`.
- **🔄 استرجاع الأصل بزر واحد:** يمكنك إلغاء التعريب والعودة للنسخة الإنجليزية في أي لحظة.
- **⚔️ تشغيل اللعبة فوراً:** زر لتشغيل اللعبة مباشرة من داخل التطبيق بعد التثبيت.

---

## 📥 طريقة التحميل والاستخدام (للاعبين)

1. حمّل ملف التثبيت المباشر **`Bloodborne_Arabic_Setup.exe`** من صفحة **[Releases](https://github.com/)**.
2. ضع الملف في مجلد اللعبة أو شغّله من أي مكان على جهازك.
3. سيتعرف البرنامج على مسار اللعبة تلقائياً (أو اضغط **"استعراض... / Browse"** لتحديد مجلد اللعبة).
4. اختر **"🇪🇬 تعريب بالمصري"** ثم اضغط **"🩸 تثبيت التعريب الآن"**.
5. بعد اكتمال التثبيت، اضغط **"⚔️ تشغيل اللعبة"** واستمتع باللعبة بالعربي!

> [!IMPORTANT]
> **ملاحظة هامة:** تأكد من أن لغة اللعبة داخل الإعدادات مضبوطة على **English** لأن التعريب يستبدل ملفات اللغة الإنجليزية بالخطوط والنصوص العربية المشكلة.

## 🛠️ التشغيل من المصدر (للمطورين)

إذا كنت ترغب في تشغيل الكود المصدري أو التعديل عليه:

```bash
# 1. استنساخ المستودع
git clone https://github.com/YOUR_USERNAME/Bloodborne-PC-Arabic-Localization.git
cd Bloodborne-PC-Arabic-Localization

# 2. تثبيت المكتبات المطلوبة
pip install -r requirements.txt

# 3. تشغيل التطبيق
python Bloodborne_Arabic_Tool/main.py
```
